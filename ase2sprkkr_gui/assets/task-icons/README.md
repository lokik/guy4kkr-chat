# Optional task icons

Place a square SVG or PNG in this directory with a filename matching the
lowercase canonical native SPR-KKR task name, for example `scf.svg`,
`dos.png`, or `bsf.svg`. Filenames are lowercase.

If a matching file exists it appears next to that task in the native task
chooser, in Preferred tasks settings, and on Guided calculation cards.
If no file is supplied the existing generic Run icon is used for Guided
cards. Task names are validated before any asset path is inspected.

BSFEK and BSFKK share the single GUI task and icon `bsf.svg`.
